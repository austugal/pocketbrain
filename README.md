# PocketBrain

A small browser-based knowledge workspace by Tiago Fitas.

Import Markdown or text files, search your notes, discover shared-term connections, explore a keyboard-accessible connection map, create notes and practise recall with revision cards. No account, build step, API key or AI subscription.

[Open the live demo](https://austugal.github.io/pocketbrain/)

## Run

Open `index.html` in a modern browser. Click **Load demo** or import `.md` / `.txt` notes or restore a PocketBrain JSON export.

## Data handling

Notes stay in tab memory. Nothing is uploaded. Closing or reloading loses the workspace. Export before leaving. JSON exports can be imported to restore a workspace. Files larger than 1 MB are skipped. Note content is rendered as text, never executable HTML.

## Scope

Connections count shared words. Revision cards reveal original passages. This version does not provide semantic AI, generated quizzes, persistent storage or an animated companion.

## Contribute

Useful next contributions: Multilingual tokenisation, keyboard shortcuts and Markdown formatting. Include reproduction steps and use synthetic notes in public issues.
